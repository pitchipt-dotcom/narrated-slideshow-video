# ジョブの画像順序と表示時間

## 割当優先順位

1. 全画像に`requested_duration_seconds`がある場合、その順に配置する。合計が音声時間と10ms以内で一致しなければ拒否する。
2. 全画像に`segment_ids`がある場合、利用者指定を使う。全segmentを重複なく1回、画像順に連続して割り当てる必要がある。
3. 自動割当で画像数がsegment数以下なら、全画像を使い、連続segment群を画像順に均等配分する。
4. 画像数がsegment数より多ければ、動画全体を画像数で均等分割し、重なるsegment IDを各画像へ保存する。

部分的な時間指定、部分的なsegment指定は推測で補完せず拒否する。時間とsegmentを両方指定した場合は、segment timingから求めた各表示時間と明示時間が10ms以内で一致するときだけ受け付ける。

## 保存項目と安全条件

既存の画像ID、`order`、元ファイル名、内部保存名、論理保存パス、SHA-256を保持し、次を追加する。

- `segment_ids`
- `start_seconds`
- `end_seconds`
- `duration_seconds`

segment側の`image_id`には、そのsegment中央時刻を表示中の主画像を保存する。画像区間は0秒から最終音声終了まで隙間なく連続し、既存画像の削除、移動、上書きは行わない。新しい時間フィールドはSchema上任意で、未計画時は`null`とする。
